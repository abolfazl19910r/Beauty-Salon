# آزمون دستی زرین‌پال در sandbox — بسته‌ی 5ز (۲۰۲۶-۱۰-۳۰)

این فهرست کارهای بسته‌ی 5ز را روی **لوکال (XAMPP + PHP 8.5)** و **Docker تک‌کانتینری** می‌سنجد. پیش از آن پچ‌های `0285` تا `0293`
روی `develop` اعمال شده باشند. نتیجه‌ی هر بند (✅ یا متن خطا/عکس) را برگردانید.

## آماده‌سازی

### لوکال
1. `git am --keep-cr 0285-*.patch … 0293-*.patch`
2. `php artisan migrate` (فقط جدول تازه‌ی `zarinpal_connections`) — یا چون داده آزمایشی است `php artisan migrate:fresh --seed` و بعد `php artisan superadmin:create`
3. `php artisan optimize:clear`
4. در `.env`: `ZARINPAL_SANDBOX=true`؛ `PAYMENT_ENABLED_DRIVERS` لازم نیست (پیش‌فرض فقط `zarinpal`)؛ `ZARINPAL_CONNECT_CLIENT_ID` خالی.
   کلیدهای `ZARINPAL_PAYOUT_*` دیگر خوانده نمی‌شوند (می‌توانید پاکشان کنید).
5. **سایت را با همان نشانی `APP_URL` باز کنید** (مثلاً `http://192.168.1.2:8000`). بازگشت از درگاه حالا همیشه روی دامنه‌ی سالن است
   (با `CENTRAL_DOMAIN` خالی = میزبان `APP_URL`) و بعد به صفحه‌ای که پرداخت را از آن شروع کردید برمی‌گردد.
6. VPN خاموش (زرین‌پال IP خارج را رد می‌کند).
7. در «درگاه‌های پرداخت» سالن آزمایشی یک درگاه زرین‌پال با هر UUID دلخواه (sandbox) داشته باشید.

### Docker تک‌کانتینری
1. همان پچ‌ها؛ بعد `docker compose -f docker-compose.single.yml up -d --build` (migrate را خود ظرف می‌زند).
2. خط hosts سالن آزمایشی (مثلاً `127.0.0.1 rasta.arisheh.test`) باید باشد: بازگشت از درگاه روی
   `http://rasta.arisheh.test:8080/payments/return/…` است، حتی اگر پرداخت را از `http://arisheh.test:8080/s/rasta` شروع کنید.
3. دستورهای artisan: `docker compose -f docker-compose.single.yml exec app php artisan …`

### tinker بند ۸ (cmd ویندوز)
```bat
php artisan tinker --execute="$t = \App\Models\PaymentTransaction::latest('id')->first(); \App\Models\PaymentTransaction::whereKey($t->id)->toBase()->update(['created_at' => now()->subMinutes(61), 'updated_at' => now()->subMinutes(61)]); echo $t->id.' '.$t->status;"
php artisan payments:reconcile
php artisan tinker --execute="$t = \App\Models\PaymentTransaction::latest('id')->first(); echo $t->status.' '.$t->ref_id;"
```
(داکر: پیش از هر کدام `docker compose -f docker-compose.single.yml exec app`. با `saveQuietly` نکنید: `updated_at` را «الان» می‌کند و
reconcile تا ۱۰ دقیقه سراغش نمی‌رود.)

## آنچه در sandbox آزمودنی نیست
- خطای ‎-14 (دامنه‌ی ثبت‌شده) و ‎-18 فقط در درگاه واقعی؛ sandbox دامنه را نمی‌سنجد.
- ‎-50/‎-52 و «نیاز به بررسی» با تست‌های خودکار (`ZarinpalNeedsAttentionTest`) سنجیده شده‌اند.
- «اتصال حساب زرین‌پال» تا آمدن `client_id` و `redirect_uri` ثبت‌شده از پشتیبانی زرین‌پال (`ZarinpalConnectTest` با پاسخ‌های مستند).
